# Control Plane Profile v0.3 — Historical Note

This profile records an earlier collaboration that explored bounded-caller,
approval, effect, receipt, acceptance, and simulated-closure models.

The maintained repository surface now focuses on data-contract integrity,
database primitive findings, Practitioner Probes, Machine Nodes, and a
Coordination Horizon. Runtime identity, authorization, workflow, migration,
release, and organizational decision mechanics belong to their established
platforms.

The earlier schemas and examples remain in the repository for provenance. The
active validator excludes them. New work should begin with the maintained
surface listed in the root README.
